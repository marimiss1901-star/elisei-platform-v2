ELISEI 5.6.4 — PATCH FROM 5.6.3

Назначение: разделить Базовый и Сервисный токены WB, направить официальные финансовые сводки только через сервисный доступ и сделать очередь устойчивой к 429/5xx без потери прогресса.
Применение: распаковать папку патча и скопировать её содержимое в корень репозитория ELISEI 5.6.3 с заменой файлов.
MAXADORRE и его данные не затрагиваются.

Что меняется:
- в «Подключениях» добавлена отдельная карточка Сервисного токена WB;
- основной Базовый токен продолжает обслуживать товары, заказы, остатки, рекламу, документы, обычные финансы и коммуникации;
- Сводки реализации и Сводки эквайринга выбирают только Сервисный токен типа acc=4 с категорией «Финансы»;
- сервисный токен нельзя сделать основным или использовать в обычных потоках;
- WB_CLIENT_SECRET хранится только в backend Render, проверяется без раскрытия значения во frontend;
- статусы явно различают отсутствие сервисного токена, секрета, финансового права и недействительный токен;
- 429, 408, 425, 500, 502, 503 и 504 переводятся в автоматическую очередь повторов;
- taskId, курсор, текущая страница/месяц и ранее загруженные строки сохраняются;
- старые состояния 504/timeout/gateway восстанавливаются в retry_scheduled после перезапуска backend;
- архив FBS вынесен в отдельный worker и не блокирует финансы, документы и другие тяжёлые потоки;
- правила 5.6.3 для архива FBS, meta/details и СГТ read-only сохранены;
- backend обновлён до 2.16.0, frontend до 5.6.4.

Важно:
- для двух официальных сводок нужен зарегистрированный сервис WB, Сервисный токен продавца и переменная backend WB_CLIENT_SECRET;
- без сервисного доступа все обычные потоки продолжают работать;
- FILES.txt — инвентарный список контролируемых файлов репозитория;
- PATCH_FILES.txt — точный перечень файлов проекта, которые меняет патч;
- патч устанавливается только поверх ELISEI 5.6.3.

Проверено:
- backend npm test: 13/13 тестовых наборов пройдены;
- node --check для всех backend JS/MJS/CJS-файлов;
- TypeScript transpile-проверка 12 frontend JS/JSX-файлов: 0 ошибок;
- наложение патча на чистую 5.6.3 и побайтовая сверка всех изменяемых файлов;
- проверка целостности ZIP и внутренних SHA-256.

Количество изменяемых файлов проекта: 14.
Ограничение не более 100 файлов в архиве соблюдено.
