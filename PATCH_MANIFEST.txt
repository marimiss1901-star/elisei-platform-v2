ELISEI 5.7.0 — PATCH FROM 5.6.4

Назначение: сделать Эла живым AI-партнёром внутри проекта — с постоянным характером, адаптивным обращением, поддержкой, безопасным юмором, эмоциональными реакциями и прозрачной опорой на данные кабинета.
Применение: распаковать папку патча и скопировать её содержимое в корень репозитория ELISEI 5.6.4 с заменой файлов.
MAXADORRE и его данные не затрагиваются.

Что меняется:
- единый профиль характера для Эл Аналитик, Эл GPT и Эл Pro;
- стили «Деловой», «Дружелюбный» и «Свой человек»;
- уровни юмора off/light/noticeable, выбор обращения, поддержка и поздравления;
- распознавание усталости, раздражения, тревоги, благодарности, просьбы о похвале, шутке и подтверждённого успеха;
- обязательное отключение юмора при убытках, штрафах, удержаниях, блокировках и критических ошибках;
- неповторяющиеся тематические шутки для рекламы, остатков, финансов, возвратов, синхронизаций и успехов;
- сохранение профиля в PostgreSQL таблице el_profiles отдельно для пользователя и кабинета;
- учёт имени, текущего раздела, локального времени пользователя, единого периода, выбранного товара, истории и памяти решений;
- реакции Эла happy/thinking/concerned/supportive/proud на главной странице и в чате;
- блок «На чём основан ответ» с фактами и ограничениями;
- бесплатный Эл Аналитик остаётся локальным и не использует OpenAI API;
- финансовые, рекламные, FBS, сервисные токены и остальные WB-потоки версии 5.6.4 не изменяются;
- backend обновлён до 2.17.0, frontend до 5.7.0.

Безопасность:
- профиль нормализуется на backend, произвольные значения не сохраняются;
- noHumorInCritical всегда true и не может быть отключён интерфейсом;
- Эл остаётся read-only и не меняет цены, ставки, бюджеты, карточки или сообщения без отдельного подтверждения;
- OpenAI API вызывается только в платных режимах GPT/Pro;
- факты кабинета подтверждаются модулями ELISEI, недостаток данных показывается явно.

Важно:
- миграция el_profiles создаётся автоматически при запуске backend;
- старое boolean-поле юмора автоматически преобразуется в новый формат;
- FILES.txt — инвентарный список контролируемых файлов репозитория;
- PATCH_FILES.txt — точный перечень файлов, которые содержит патч;
- патч устанавливается только поверх ELISEI 5.6.4.
