ELISEI 5.7.3 — PATCH FROM 5.7.2

Назначение: исправить понимание временного интервала в вопросах Эла и терминологию ответов по выручке.
Применение: распаковать содержимое патча в корень репозитория ELISEI 5.7.2 с заменой файлов.
MAXADORRE и его данные не затрагиваются.

Что меняется:
- новый локальный разборщик относительных и явных дат;
- «вчера» переопределяет выбранные 7/30/90 дней только для текущего вопроса;
- frontend передаёт локальную дату, часовой пояс и UTC-смещение браузера;
- data bridge получает точный период из вопроса;
- резервная сводка экрана не используется при несовпадении периода;
- ответы различают заказы и проданные единицы;
- короткий вопрос о выручке не сопровождается лишней оговоркой о товарах;
- frontend обновлён до 5.7.3, backend до 2.17.3;
- WB API и фоновые синхронизации не меняются.

Безопасность и достоверность:
- дата из текста не меняет глобальный период кабинета;
- максимальный период «последние N дней» ограничен 366 днями;
- некорректные даты не принимаются;
- при отсутствии данных за точный день Эл не подставляет значения другого периода;
- действия Эла остаются read-only.
