# ELISEI 5.7.4

Патч устанавливается поверх 5.7.3.

## Исправления

1. Точный ответ за день: frontend передаёт Элу дневную динамику и покрытие потоков, а backend использует строку только нужной даты.
2. При задержке WB Эл пишет, до какой даты данные подтверждены, вместо сообщения о неподключённом кабинете.
3. Сохранённое имя не стирается пустым значением из старого интерфейса. Имя аккаунта и имя для общения с Элом разделены.
4. Выбранный глобальный период не меняется — дата из вопроса действует только для ответа.

После установки очистите build cache backend и frontend. Затем в настройках Эла один раз укажите нужное имя и начните новый диалог.
