ELISEI 5.12.0 — emergency password reset hotfix

Changed files:
- backend/src/server.js
- src/lib/api.js
- src/pages/LoginPage.jsx

Usage after deploy:
1. Open /login and click «Забыли пароль?».
2. Enter the ELISEI account email.
3. Open Render backend service logs.
4. Find line beginning: [ELISEI PASSWORD RESET]
5. Open the one-time URL within 15 minutes.
6. Set a new password (minimum 8 characters), then sign in.

Security:
- reset URL is never returned by the public API;
- it is logged only in backend logs until an email provider is connected;
- token expires in 15 minutes;
- changing the password invalidates the token, making it one-time.
