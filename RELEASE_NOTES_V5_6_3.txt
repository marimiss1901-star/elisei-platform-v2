ELISEI 5.6.3
Дата: 04.08.2026
База обновления: ELISEI 5.6.2

ГЛАВНЫЙ ПРИОРИТЕТ
- Проверен и усилен архив сборочных заданий FBS.
- Устаревшие методы meta/info заменены актуальными meta/details и заблокированы на уровне сетевого клиента.
- Управление СГТ-складами через API не добавляется; существующие склады доступны только для чтения.

АРХИВ FBS
- Используется GET /api/marketplace/v3/fbs/orders/archive.
- Загрузка идёт помесячно, limit=1000, с полным продолжением по next.
- Пустая страница с ненулевым новым next больше не завершает месяц преждевременно.
- Зациклившийся next определяется как ошибка без удаления уже сохранённых данных.
- Ключи строк стабильны между страницами и повторами.
- План месяцев фиксируется в состоянии очереди и восстанавливается после перезапуска.
- Поддержано продолжение очереди, начатой на версии 5.6.2.
- После завершения сохраняются monthStats, archiveCutoff и подтверждение cursorComplete.
- Интерфейс показывает месяц, страницу, сохранённые строки и итоговое покрытие.

МЕТАДАННЫЕ ЗАКАЗОВ
- DBS: только POST /api/marketplace/v3/dbs/orders/meta/details.
- DBW: только POST /api/marketplace/v3/dbw/orders/meta/details.
- Самовывоз: только POST /api/marketplace/v3/click-collect/orders/meta/details.
- Старые meta/info и DBW GET {orderId}/meta возвращают внутреннюю ошибку политики 410 до обращения к WB.
- Добавлен единый построитель запросов meta/details.

СГТ-СКЛАДЫ
- Существующие cargoType=2 читаются из GET /api/v3/warehouses и участвуют в остатках FBS.
- ELISEI не строит список допустимых типов по GET /api/v3/offices.
- POST/PUT для cargoType=2 блокируются.
- После 05.08.2026 изменение склада без известного cargoType блокируется как небезопасное.
- В интерфейсе отображается режим «СГТ-склады — только чтение».

ДИАГНОСТИКА И ВЕРСИИ
- /health показывает wbApiPolicy.
- Frontend: 5.6.3.
- Backend: 2.15.0.
- User-Agent backend обновлён до ELISEI/2.15.0.

ТЕСТЫ
- Добавлены тесты WB API policy и FBS archive.
- Проверяются замена endpoint, блокировка СГТ, курсорная пагинация, пустые страницы, защита от зацикливания, стабильные ключи и восстановление старой очереди.
