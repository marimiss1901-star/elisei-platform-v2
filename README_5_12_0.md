# ELISEI 5.12.0 — SKU 360 Change Diagnostics

Устанавливается поверх ELISEI 5.11.6 с заменой файлов.

Что нового:
- SKU 360 автоматически сравнивает выбранный период с предыдущим равным периодом.
- Дельты: выручка, заказы/продажи, возвраты, средняя цена, реклама, ДРР, прибыль, комиссия и логистика — только если соответствующие данные подтверждены в обоих периодах.
- Блок «Что изменилось и почему» показывает до 4 главных диагностических факторов и их денежный масштаб.
- Блок «Одно действие» выбирает первый шаг, а не предлагает менять всё сразу.
- Неполное покрытие предыдущего периода скрывает недостоверное сравнение вместо ложных нулей.
- Текущий остаток не используется как историческая причина без подтверждённой истории остатков.
- Никаких новых запросов к WB: сравнение строится на уже сохранённых данных ELISEI.

После деплоя проверь `/health`: backend должен вернуть 2.24.0.
