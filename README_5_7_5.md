# ELISEI 5.7.5 — связный диалог с Элом

Патч устанавливается поверх ELISEI 5.7.4.

## Что исправлено

1. Эл распознаёт короткие уточнения: «из них», «а сколько FBS?», «а возвратов?», «какие товары?».
2. Уточнение наследует период и тему предыдущего ответа. Явно указанная новая дата всегда имеет приоритет.
3. Период хранится в серверной истории диалога и не зависит от визуального состояния сообщения в браузере.
4. Заказы разбиваются на FBS и FBO по фактической схеме каждой строки заказа.
5. Заказы с неподтверждённой схемой показываются отдельно и не добавляются ни в FBS, ни в FBO.
6. Если схема не определена ни у одной строки, Эл не показывает ложные нули FBS/FBO.
7. Короткое уточнение получает короткий ответ без повторения всей сводки.

## Пример

После ответа «Заказов — 9 111» вопрос:

> сколько из них заказов FBS?

получит ответ вида:

> Из 9 111 заказов за 29 июля — 4 августа 2026 года: FBS — 2 480, FBO — 6 500. Без подтверждённой схемы — 131.

Числа в реальном кабинете рассчитываются из сохранённых строк WB.

## Установка

1. Заменить файлы патча поверх версии 5.7.4.
2. Backend: `Clear build cache & deploy`.
3. Frontend: `Clear build cache & deploy`.
4. Обновить кабинет через `Ctrl + F5` и начать новый диалог либо продолжить текущий.
