# ELISEI Design Language

- Фон: тёмный графит.
- Основной акцент: фиолетовый.
- Дополнительный акцент: голубой.
- Успех: изумрудный.
- Предупреждение: янтарный.
- Карточки: стекло, мягкая глубина, радиус 18–24 px.
- Анимации: 120–250 ms для интерфейса, плавная ambient-анимация только для ЭЛа.
- На экране одновременно не более трёх главных решений.
- Каждая рекомендация содержит: причину, ожидаемый эффект и действие.
