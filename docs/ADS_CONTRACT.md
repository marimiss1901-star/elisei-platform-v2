# ELISEI — контракт рекламного центра WB

## Источник

Модуль использует только методы чтения WB Promotion API:

- `GET /adv/v1/promotion/count` — список кампаний;
- `GET /adv/v3/fullstats` — статистика кампаний;
- `GET /api/advert/v1/config` — валюта кабинета и настройки продвижения.

Операции запуска, остановки, изменения ставок и пополнения бюджета не выполняются.

## Авторизация

```env
WB_PROMOTION_TOKEN=...
```

Токен должен иметь категорию **Продвижение**. `WB_API_TOKEN` используется только как резервное имя переменной.

## Период

Каждый endpoint принимает глобальный период Елисея:

```text
date_from=2026-07-01
date_to=2026-07-30
compare=1
compare_from=2026-06-01
compare_to=2026-06-30
```

Диапазоны длиннее 31 дня автоматически делятся на части. Кампании запрашиваются пакетами до 100 ID.

## Endpoint Елисея

- `GET /api/ads/health`
- `GET /api/ads/overview`
- `GET /api/ads/campaigns`
- `GET /api/ads/products`
- `GET /api/ads/el-insights`
- `POST /api/ads/sync`

## Прибыль после рекламы

Для точного расчёта добавьте файл `backend/data/product-unit-economics.json`:

```json
{
  "123456789": {
    "vendorCode": "EL-001-BLACK",
    "title": "Название товара",
    "photo": "https://...",
    "stock": 24,
    "cogsPerUnit": 1200,
    "commissionRate": 0.25,
    "logisticsPerUnit": 180
  }
}
```

Формула:

```text
Прибыль после рекламы = рекламная выручка
                      - себестоимость проданных единиц
                      - комиссия маркетплейса
                      - логистика
                      - рекламный расход
```

Рекламная статистика связывается с товаром по `nmID`. Артикул продавца, фото и остаток берутся из единого справочника товаров.
