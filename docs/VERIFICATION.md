# Проверка релиза ELISEI 5.3

Проверено локально при сборке пакета:

- синтаксис backend (`node --check`);
- разбор JSX всех страниц через TypeScript transpiler;
- корректность `package.json`;
- баланс CSS-блоков;
- отсутствие очевидных токенов, строк подключения к БД и секретов в архиве;
- объединение инкрементальных заказов/продаж без удаления предыдущего среза;
- нормализация отчёта остатков по физическим складам;
- агрегация рекламных метрик;
- число файлов в архиве меньше 100.

Не выполнялось:

- запросы к реальному кабинету Wildberries — секретные токены пользователя не передаются разработчику;
- полная Vite-сборка в локальной среде: доступный npm-реестр не вернул `lucide-react`.

После деплоя контроль выполняется по `/health`, менеджеру токенов и отдельным статусам пяти потоков: товары, заказы, продажи, остатки и реклама.
