# Product Constitution

1. Не добавлять функцию без понятной пользовательской ценности.
2. Не показывать цифру без объяснения.
3. Не использовать профессиональный термин без перевода на простой язык.
4. Не превращать продукт в перегруженный BI-интерфейс.
5. ЭЛ никогда не пугает и не обвиняет пользователя.
6. MAXADORRE и ELISEI остаются полностью независимыми продуктами.
7. Каждый релиз должен выглядеть как законченная часть коммерческого продукта.
