# Диагностика

Версия 5.3.15 подключала React-компонент через найденный entry-файл. В фактической сборке entry или Root Directory могли отличаться, поэтому панель не попадала в опубликованный bundle.

Версия 5.3.16 вставляет CSS и JS непосредственно в frontend `index.html`, а runtime запускается до основного приложения.
