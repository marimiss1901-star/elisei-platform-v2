# ELISEI 5.13.2 — Closed-Day Backfill

Daily Ready теперь не просто хранит вчерашний снимок, но и восстанавливает пропущенное покрытие закрытого дня.

- Если orders/sales не покрывают вчерашнюю дату, ELISEI автоматически ставит точечный backfill в Smart Scheduler.
- Backfill статистики берёт сутки запаса до целевой даты, поэтому дырка не теряется даже если в потоке уже есть более новые строки.
- Вход пользователя не запускает WB API: восстановление идёт только фоновым worker.
- Реальный next_allowed_at / rate limit WB всегда сохраняется.
- Успешный запрос подтверждает день даже при законных 0 строках, чтобы не было бесконечных повторов.
- Реклама также проверяется по покрытию периода и при необходимости обновляется отдельным фоновым этапом.

Версии: frontend 5.13.2, backend 2.25.2, El Core 5.13.2.
