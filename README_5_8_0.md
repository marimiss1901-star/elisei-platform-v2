# ELISEI 5.8.0 — финансовое ядро WB

Патч устанавливается поверх ELISEI 5.7.6.

## Главный результат

Финансовая детализация и документы больше не поставлены в зависимость от отдельного Сервисного токена. ELISEI проверяет и использует реальные права текущего Базового токена:

- категория «Финансы» — детализированный отчёт реализации и баланс;
- категория «Документы» — категории, список и скачивание документов;
- Персональный/Сервисный доступ — только дополнительные официальные сводки реализации, эквайринга и статус подписки «Джем».

## Финансовая детализация

1. Используется `POST /api/finance/v1/sales-reports/detailed`.
2. Период и точный курсор `rrdId` сохраняются между попытками.
3. Каждая полученная страница сразу записывается в PostgreSQL.
4. Загрузка завершается только после ответа WB без следующей страницы, а не по размеру короткой страницы.
5. Для Базового токена соблюдается интервал 12 часов; ручные повторные нажатия не обнуляют прогресс.
6. Int64-значения курсоров сохраняются без округления JavaScript.
7. Дубли устраняются по стабильному ключу финансовой операции.

## Полный финансовый реестр

В единый реестр входят подтверждённые операции WB:

- выручка и сумма к перечислению;
- комиссия WB;
- прямая и обратная логистика;
- хранение и платная приёмка;
- эквайринг;
- штрафы, удержания, корректировки и компенсации;
- возвраты и возмещения;
- рекламные списания;
- подписки, включая подтверждённые списания «Джем»;
- прочие операции, возвращённые финансовым отчётом.

Операция хранит дату, сумму, знак, тип, источник, идентификаторы товара/заказа и доступные признаки FBS/FBO. Детализирующие источники не уменьшают прибыль повторно.

## Документы WB

Добавлен отдельный рабочий раздел «Документы WB»:

- категории документов;
- список документов с датой, номером, типом и периодом;
- фильтр по категории и общий поиск;
- безопасное скачивание через backend без передачи токена в браузер;
- отображение частичного покрытия и следующей разрешённой попытки;
- поиск документов, подтверждающих подписку или списание «Джем».

Для методов категорий, списка и скачивания документов учитывается официальный интервал 10 секунд; ELISEI использует безопасную паузу 11 секунд. Уже загруженные строки сохраняются.

## «Джем»

ELISEI разделяет:

- статус подписки — информационный сигнал, доступный отдельным сервисным методом;
- списание денег — только подтверждённая финансовая операция или документ.

При отсутствии подтверждения интерфейс пишет «списание не подтверждено», а не показывает ноль и не рассчитывает сумму по статусу подписки.

## Эквайринг

Для Базового токена эквайринг формируется из строк детализированного финансового отчёта. Официальная отдельная сводка эквайринга остаётся контрольным дополнительным источником и не блокирует основной P&L.

## Защита данных

- финансовый курсор и частичные страницы переживают deploy и паузы WB;
- лимит, временная ошибка и отсутствие права отображаются разными статусами;
- токены не возвращаются во frontend;
- документы скачиваются только через авторизованный backend пользователя;
- до полной загрузки нет ложных нулей.

## Установка

1. Наложить патч поверх версии 5.7.6.
2. Backend Render: `Clear build cache & deploy`.
3. Frontend Render: `Clear build cache & deploy`.
4. Обновить кабинет через `Ctrl + F5`.
5. В «Синхронизациях» запустить доступные этапы либо дождаться запланированного повтора финансов и документов.
