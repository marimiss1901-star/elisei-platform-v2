# ELISEI 5.11.4 — SKU 360 Data Isolation

Hotfix поверх 5.11.3.

- Поиск SKU 360: только `rowType=query` + строгая identity-привязка.
- Overview/group поисковые строки не могут попасть в конкретный SKU.
- Реклама SKU 360: только точное совпадение `nmID`; vendor/barcode fallback для рекламных денег запрещён.
- KPI рекламы и строка экономики не используют распределённый кабинетный расход как будто это точный расход SKU.
- Batch `product/search-texts` уменьшен до официального максимума 20 nmIds.
- Название товара по-прежнему никогда не используется для join.
