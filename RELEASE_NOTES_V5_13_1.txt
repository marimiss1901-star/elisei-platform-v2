ELISEI 5.13.1 / backend 2.25.1 / El Core 5.13.1 — PERSISTENT DAILY SNAPSHOT

- Вчерашние подтверждённые данные больше не зависят от текущего статуса очереди WB.
- Persisted coverage за дату имеет приоритет над queued/running/rate_limited нового refresh.
- Last-known-good snapshot не позволяет подтверждённым KPI исчезать обратно в «Ожидается».
- Daily Ready endpoint отдаёт сохранённый снимок сразу; refresh существующего снимка идёт асинхронно и без WB API на входе.
- Финансы по-прежнему не получают ложный статус ready: при неполной детализации показываются как partial.
- UI: «Снимок за вчера дополняется» / «Снимок за вчера доступен» / «Вчерашний день подтверждён».
