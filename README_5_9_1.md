# ELISEI 5.9.1 — Контроль данных

Патч устанавливается поверх ELISEI 5.9.0.

## Что добавлено

На странице «Синхронизации» появился единый центр качества данных с тремя вкладками:

- **Проблемы и действия** — критические разрывы, предупреждения и понятные следующие шаги.
- **Паспорта потоков** — количество строк, источник, покрытие, свежесть, статус и причина ожидания.
- **Финансовая сверка** — движение реестра, сумма к перечислению, расходы, расхождение и допустимый порог.

ELISEI больше не считает неполный период подтверждённым. При частичной загрузке прибыль получает статус «предварительная», а до появления финансовых строк — «ожидает данные».

## Новый endpoint

`GET /api/wb/data-quality/:connectionId?from=YYYY-MM-DD&to=YYYY-MM-DD`

Возвращает:

- итоговую готовность данных;
- общий подтверждённый период;
- уверенность прибыли;
- паспорта всех WB-потоков;
- список проблем и действий;
- финансовую сверку;
- диагностику товарного сопоставления.

## Проверка после установки

1. Выполнить Clear build cache & deploy для backend.
2. Затем выполнить Clear build cache & deploy для frontend.
3. Открыть «Синхронизации» и нажать Ctrl+F5.
4. Проверить вкладки «Проблемы и действия», «Паспорта потоков» и «Финансовая сверка».

Backend: 2.20.0. Frontend: 5.9.1.
