ELISEI v5.1.3 — WB Basic Token Fix

Исправлено:
- Базовый токен WB больше не требует WB_CLIENT_SECRET.
- WB_CLIENT_SECRET обязателен только для Сервисного токена.
- При подключении выполняется лёгкая официальная проверка /ping вместо запроса отчёта остатков.
- HTTP-коды ошибок WB больше не подменяются общим кодом 400.
- Backend: 2.5.4.

Важно:
- Не создавайте новый API-токен только из-за сообщения о WB_CLIENT_SECRET.
- Для Базового токена переменная WB_CLIENT_SECRET в Render не нужна.
- После деплоя повторно нажмите «Проверить и подключить», используя текущий токен.
