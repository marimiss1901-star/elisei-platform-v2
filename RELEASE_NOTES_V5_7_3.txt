ELISEI 5.7.3 — EL NATURAL DATE INTENT HOTFIX

- Дата из вопроса Эла имеет приоритет над общим периодом интерфейса только для текущего ответа.
- Добавлено понимание: сегодня, вчера, позавчера, текущая/прошлая неделя, текущий/прошлый месяц, текущий/прошлый год, последние N дней, конкретная дата и диапазон.
- Расчёт выполняется по локальной дате браузера пользователя, а не по UTC Render.
- Недельная сводка текущего экрана больше не подставляется в ответ на вопрос про один день.
- Исправлена терминология: «заказы» и «проданные единицы» показываются отдельно.
- Товарная детализация упоминается только по запросу товаров/артикулов/лидеров.
- Backend: 2.17.3. Frontend: 5.7.3.
- WB API, финансы, архив FBS, реклама и очереди синхронизации не изменяются.
