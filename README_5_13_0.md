# ELISEI 5.13.0 — Daily Ready

Цель релиза: пользователь открывает кабинет и сразу видит готовые цифры за вчера, не ожидая старта WB-потоков.

## Что изменено

1. **Готовый снимок за вчера.** Backend сохраняет `wb_daily_snapshots` в PostgreSQL отдельно по кабинету и дате. Снимок содержит KPI, топ товаров, рекламу, финансовую сводку, предыдущий день и состояния доверия.
2. **Вход не запускает WB API.** `GET /api/wb/daily-ready/:id` читает сохранённый снимок; при необходимости пересчитывает его только из уже сохранённых данных ELISEI.
3. **Автоматическая умеренная синхронизация.** Заказы и продажи — ориентир 30 минут; реклама и остатки — 60 минут; товары — 6 часов; отзывы/вопросы — 3 часа; чаты — 1 час. Smart Scheduler и `next_allowed_at` остаются окончательным ограничителем.
4. **Тяжёлая финансовая полоса.** Finance/acquiring/storage/acceptance не привязаны к частоте оперативных потоков и не спамят WB.
5. **Честные статусы.** `ready / partial / waiting / missing`; неподтверждённый ноль не показывается как факт.
6. **Главная по умолчанию — «Вчера».** Сразу видны выручка, заказы, продажи, возвраты, реклама, расходы и прибыль в пределах доступного покрытия.
7. **Free Render wake-up.** `.github/workflows/elisei-daily-ready-wake.yml` будит текущий backend в 05:00, 07:30 и 11:30 МСК. Сам wake не запускает все API безусловно — внутренний Smart Scheduler выбирает только due-этапы. Для будущей коммерческой эксплуатации предпочтителен always-on backend/worker.
8. **Ручной запуск — только диагностика.** Пользовательский сценарий больше не строится вокруг кнопки «Запустить потоки».

## Версии

- Frontend: `5.13.0`
- Backend: `2.25.0`
- El Core: `5.13.0`

## Проверка после деплоя

- `/health` должен вернуть backend `2.25.0`.
- На Главной период по умолчанию — «Вчера».
- Над KPI появляется баннер готовности снимка.
- В «Подключениях» показан режим AUTO, без пользовательского тумблера включения/выключения.
- В «Синхронизациях» основной режим — автоматический, ручной запуск помечен как диагностический.
- Старые правила Data Confidence и SKU 360 сохраняются.
