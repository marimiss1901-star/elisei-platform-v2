# ELISEI 5.4.5A — Backend Profit Hotfix

Исправляет ошибку запуска/работы backend:

```text
ReferenceError: sharedExpenses is not defined
```

## Установка

Загрузите содержимое архива в корень репозитория с заменой файлов.

Render backend:

- Root Directory: `backend`
- Build Command: `npm install`
- Start Command: `npm start`

Затем запустите **Manual Deploy → Clear build cache & deploy**.

Frontend обновлять не требуется.
