# ELISEI 5.7.3 — Эл понимает даты из вопроса

Патч устанавливается поверх ELISEI 5.7.2.

## Исправленная ошибка

Раньше вопрос «Что с выручкой за вчерашний день?» мог использовать период, выбранный в интерфейсе, например последние 7 дней. Теперь дата из сообщения имеет приоритет только для текущего ответа Эла.

При локальной дате пользователя 4 августа 2026 года:

- «сегодня» → 4 августа 2026 года;
- «вчера» / «за вчерашний день» → 3 августа 2026 года;
- «позавчера» → 2 августа 2026 года.

Выбранный период в остальных разделах кабинета при этом не изменяется.

## Поддерживаемые формулировки

- сегодня, вчера, позавчера;
- текущая и прошлая неделя;
- текущий и прошлый месяц;
- текущий и прошлый год;
- последние N дней;
- конкретная дата: `03.08.2026`, `3 августа`;
- диапазон: `01.08.2026–03.08.2026`, `с 1 по 3 августа`.

Дата рассчитывается по локальной дате браузера пользователя, а не по часовому поясу сервера Render.

## Ответы по выручке

Короткий вопрос по общей выручке теперь получает короткий ответ:

> Мария, за 3 августа 2026 года выручка составила … ₽. Заказов — …, проданных единиц — …. Возвраты — … шт.

Исправлена терминология:

- заказы и проданные единицы показываются отдельно;
- фраза «продаж из заказов» больше не используется;
- предупреждение о товарной детализации выводится только тогда, когда пользователь действительно просит товары, артикулы, лидеров или топ продаж.

## Защита от неверного периода

Если пользователь спросил про вчера, Эл не имеет права подставить недельную сводку текущего экрана при временном сбое внутреннего data bridge. При отсутствии строк именно за нужную дату он честно сообщает о недостатке данных.

## Версии

- Frontend: `5.7.3`
- Backend: `2.17.3`

## Проверка после установки

1. Выполнить **Clear build cache & deploy** для backend.
2. Выполнить **Clear build cache & deploy** для frontend.
3. Обновить кабинет через `Ctrl + F5`.
4. Начать новый диалог и спросить: «Что с выручкой за вчерашний день?»
5. В ответе должна быть одна дата — вчерашний день по локальному времени пользователя.
