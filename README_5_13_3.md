# ELISEI 5.13.3 — Daily Ready Recovery Lane

Hotfix поверх 5.13.2. Закрытие вчерашнего дня получает приоритетную последовательную lane: orders → sales → advertising. За один цикл Smart Scheduler выбирается только один recovery-поток на кабинет; остальные due recovery-потоки сдвигаются минимум на 70 секунд. Это предотвращает конкуренцию закрытия дня с общей фоновой очередью и делает UI честным: due rate-limit означает «готов к автоповтору», а не фактически запущенный запрос.

Версии: frontend 5.13.3, backend 2.25.3, El Core 5.13.3.
