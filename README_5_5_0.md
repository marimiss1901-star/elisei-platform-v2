# ELISEI 5.5.0 — реклама, поиск и коммуникации WB

Прямое обновление поверх **ELISEI 5.4.9**. MAXADORRE и его данные не затрагиваются.

## Что добавлено

### Полная реклама

- все кампании со статусами 4, 7, 8, 9 и 11;
- статистика `fullstats` партиями до 50 кампаний с автоматическим продолжением;
- показатели по кампании и товару: показы, клики, расход, заказы, выручка, CTR, CPC, конверсия клика в заказ, CRR и ROMI;
- дневная динамика за 30 дней;
- фильтры, вкладки «Кампании / Товары / Динамика» и CSV для Excel;
- пустой ответ WB не превращается в ложные нули.

### Поисковые запросы

- сводный отчёт `/api/v2/search-report/report` с пагинацией;
- топ поисковых фраз по товарам через `/api/v2/search-report/product/search-texts`;
- товары отправляются партиями не более 50 `nmID`;
- запросы соблюдают лимит 3 запроса в минуту;
- подписка «Джем» отображается отдельным статусом `subscription_required`, а не нулевой статистикой;
- данные сохраняются постранично в PostgreSQL и продолжаются после перезапуска.

### История остатков

- официальный ежедневный CSV-отчёт `STOCK_HISTORY_DAILY_CSV`;
- период до 90 дней;
- создание задания, проверка статуса, повтор при `FAILED`, загрузка ZIP и разбор CSV;
- остатки по дате, товару и складу;
- текущий срез остатков и история хранятся раздельно;
- защита от повреждённых и чрезмерно больших ZIP-архивов.

### Отзывы и вопросы

- необработанные и архивные отзывы;
- отвеченные и неотвеченные вопросы;
- автоматическое деление истории вопросов на временные окна, если в периоде больше 10 000 строк;
- рейтинг, текст, плюсы, минусы, ответ, просмотренность и связь с товаром;
- пакетное хранение без двойного сохранения одинакового ID.

### Чаты

- список чатов и события через WB API;
- курсорное продолжение `next`;
- режим **только чтение**;
- отправка сообщений в этой версии не включена;
- служебные поля `replySign` и `signature` удаляются до сохранения и не возвращаются в браузер.

## Архитектура

Количество контролируемых потоков WB увеличено с **17 до 22**:

`searchQueries`, `stockHistory`, `reviews`, `questions`, `chats` добавлены в общую очередь, PostgreSQL-хранилище, статусы подключения и диагностику.

## Установка

Архив является патчем поверх версии 5.4.9. Скопируйте его содержимое в корень репозитория с заменой файлов.

Backend Render:

- Root Directory: `backend`
- Build Command: `npm install`
- Start Command: `npm start`

Frontend Render:

- Root Directory: пусто
- Build Command: `npm install && npm run build`
- Publish Directory: `dist`

Сначала выполните `Clear build cache & deploy` для backend, затем для frontend. После деплоя запустите новые потоки из «Синхронизаций» или откройте соответствующий раздел и нажмите «Обновить».
