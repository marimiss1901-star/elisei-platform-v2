ELISEI 5.3.4 — STOCK TRUTH FIX

- Старые неподтверждённые остатки больше не показываются как реальные.
- Остатки принимаются в расчёты только из официального отчёта WB warehouse_remains с метаданными происхождения.
- Новый отчёт всегда заменяет предыдущий снимок, в том числе когда суммарный остаток равен 0.
- Журнал показывает отдельно количество строк отчёта и количество единиц: например «15 строк · 0 шт.».
- Добавлена дата получения снимка, число товаров, складов, нулевых и ненулевых строк.
- Backend API version: 2.7.3.
