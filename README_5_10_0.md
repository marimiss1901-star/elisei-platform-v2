# ELISEI 5.10.0 — Эл 2.0: изменения → причины → деньги → действие

Первый релиз нового decision-слоя Эла. Он не добавляет новую вкладку и не использует OpenAI API: анализ строится локально на данных кабинета ELISEI.

## Что умеет

- автоматически сравнивает выбранный период с предыдущим периодом той же длины;
- показывает изменение прибыли или, если себестоимость не настроена, выручки;
- сопоставляет выручку, заказы, продажи, возвраты и ключевые расходы;
- ищет товарные драйверы снижения выручки/прибыли и роста возвратов;
- оценивает денежный масштаб причины: прямой рост расхода, снижение прибыли товара или риск выручки;
- выбирает одно главное действие вместо длинного списка общих рекомендаций;
- показывает уверенность вывода и прямо сообщает, если предыдущий период покрыт данными не полностью.

## Примеры запросов

- «Что изменилось за эту неделю?»
- «Почему упала прибыль?»
- «Что сейчас важнее всего по кабинету?»
- «Разбери причины падения и скажи одно главное действие»

## Важные ограничения

- остатки — текущий снимок, поэтому изменение остатков во времени не объявляется причиной без истории остатков;
- при отсутствии себестоимости Эл сравнивает выручку, а не выдумывает прибыль;
- корреляция не объявляется доказанной причинностью;
- модуль `diagnostics` внутренний и не создаёт новую вкладку в интерфейсе.
