ELISEI 5.3.1 — UNIVERSAL WB TOKEN PRIORITY
Дата: 29.07.2026

Что изменено
- Один API-токен с нужными категориями теперь может обслуживать все потоки WB.
- Самый полный токен автоматически назначается основным.
- Для каждого потока ELISEI сначала использует основной токен.
- Дополнительный токен используется только при отсутствии нужной категории в основном.
- Запросы не дублируются через запасные токены.
- В интерфейсе показывается режим подключения: один универсальный, комбинированный или частичный.
- Отображается, какой токен отвечает за каждый поток.
- Можно вручную назначить другой токен основным.
- При удалении основного токена система автоматически выбирает следующий наиболее полный.
- Исправлены две ошибки ядра 5.3.0: повторное добавление предупреждения и дублированное объявление переменной при расчёте выручки.

Версии
- Frontend: 5.3.1
- Backend: 2.7.1

После установки
1. Передеплоить backend с очисткой кэша.
2. Проверить /health — версия 2.7.1.
3. Передеплоить frontend с очисткой кэша.
4. Открыть «Подключения»: универсальный ключ должен иметь отметку «Основной» и покрытие 5/5 потоков, если в нём есть Контент, Статистика, Аналитика и Продвижение.
