# ELISEI 5.4.2 — настоящий встроенный Эл

Этот патч заменяет статический чат в разделе «Спросить ЭЛа» на реальный AI-чат через OpenAI Responses API.

## Главное исправление

Раньше `DashboardPage.jsx` отвечал функцией `answerFromCore()` — набором заранее написанных фраз. Поэтому вопрос о рекламе мог получить шаблонный ответ про себестоимость.

В 5.4.2 этот код полностью удалён. Встроенный чат напрямую вызывает защищённый backend `/api/el/chat`.

## Возможности

- GPT-5.6 как интеллект Эла;
- инструменты ELISEI: продажи, реклама, остатки, финансы, товары, возвраты, отзывы, цены, сезонность, закупки и синхронизации;
- объединение нескольких модулей в одном ответе;
- интернет-поиск с источниками;
- память разговора и устойчивых правил пользователя;
- постоянное хранение памяти в PostgreSQL;
- выбранный кабинет и период передаются в каждый вопрос;
- адаптивный стиль и уместный юмор;
- только read-only действия без самовольного изменения ставок, цен и бюджетов.

## Установка

Загрузить **содержимое архива в корень репозитория ELISEI** с заменой файлов. Дополнительные `apply-*.mjs` не нужны.

### Backend Render

- Root Directory: `backend`
- Build Command: `npm install`
- Start Command: `npm start`

Переменные:

```env
OPENAI_API_KEY=...
ELISEI_AI_MODEL=gpt-5.6
ELISEI_REASONING_EFFORT=medium
ELISEI_WEB_SEARCH=true
```

`DATABASE_URL`, `JWT_SECRET`, `ENCRYPTION_KEY` остаются существующими.

### Frontend Render

- Root Directory: пусто
- Build Command: `npm install && npm run build`
- Publish Directory: `dist`

`VITE_API_BASE_URL` остаётся адресом backend ELISEI.

После загрузки выполнить **Clear build cache & deploy** сначала backend, затем frontend.

## Проверка

Открыть «Спросить ЭЛа» и задать:

> Какие рекламные кампании съедают прибыль? Покажи расходы, ДРР, заказы и ограничение расчёта, если не заполнена себестоимость.

Правильное поведение: Эл сначала показывает доступные рекламные данные. Если себестоимость не заполнена, он отмечает это только как ограничение точной прибыли, а не заменяет весь ответ шаблонной инструкцией.

## Важно

Старые файлы `public/elisei-el.js` и `public/elisei-el.css` могут остаться в репозитории, но `index.html` больше их не подключает. Рабочий чат теперь встроен непосредственно в React-интерфейс.
