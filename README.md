# ELISEI v0.7 — Public Landing

Чистый React/Vite-проект без вложенных дублей.

Маршруты:
- `/` — публичный лендинг
- `/login` — вход
- `/register` — регистрация
- `/app` — кабинет

## Локальный запуск

```bash
npm install
npm run dev
```

## Сборка

```bash
npm run build
```

## Render

Проект готов для Static Site. Файл `render.yaml` находится в корне, SPA rewrite настроен на `/index.html`.
