# ELISEI v1.0 Premium

Публичный SaaS-фронтенд ELISEI: лендинг, регистрация, вход и демонстрационный кабинет.

Маршруты:
- `/` — публичный лендинг
- `/login` — вход
- `/register` — регистрация
- `/app` — кабинет

Render Static Site:
- Build command: `npm install && npm run build`
- Publish directory: `dist`
- Rewrite: `/*` → `/index.html`
