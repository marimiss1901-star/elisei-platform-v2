# ELISEI 5.13.1 — Persistent Daily Snapshot

Hotfix поверх 5.13.0. Цель: вчерашние подтверждённые цифры не должны исчезать с Главной только потому, что очередной фоновый refresh сейчас queued/running/rate-limited.

Что изменено:
- Daily Ready доверяет сохранённому покрытию данных за закрытый день, а не текущему статусу очереди Scheduler.
- Если orders/sales/advertising уже сохранены с покрытием вчерашней даты, они остаются `ready` во время следующего фонового обновления.
- Финансы остаются `partial`, пока финансовый набор не подтверждён полностью, но уже сохранённые движения не превращаются обратно в «Ожидается».
- Добавлен last-known-good merge: подтверждённая метрика за вчера сохраняется, пока новый refresh не даст новый подтверждённый вариант.
- Вход пользователя отдаёт сохранённый snapshot сразу. Устаревший снимок обновляется в фоне из БД и не блокирует открытие Главной.
- Тексты интерфейса различают: «снимок дополняется», «снимок доступен» и «вчерашний день подтверждён».

Версии:
- Frontend: 5.13.1
- Backend: 2.25.1
- El Core: 5.13.1

Проверка:
- backend regression suite: 39/39 команд прошли;
- `node --check` для server.js, daily-ready.js и elCore.cjs прошёл;
- отдельный тест проверяет, что queued/running refresh не скрывает уже подтверждённые данные;
- отдельный тест проверяет last-known-good сохранение выручки и финансов.
