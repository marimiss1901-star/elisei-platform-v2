# ELISEI 5.3.12 — WB Advertising Center

Продолжение патча 5.3.11. Добавляет полноценный рекламный центр Елисея для Wildberries.

## Что добавлено

- синхронизация кампаний и статистики WB Promotion API;
- аналитика по кампаниям и по товарам `nmID`;
- расход, рекламная выручка, показы, клики, заказы;
- CTR, CPC, CPO, конверсия, ДРР, ROAS и ROMI;
- прибыль после рекламы с учётом себестоимости, комиссии и логистики;
- сравнение с предыдущим аналогичным периодом;
- единый глобальный период: день / неделя / месяц / произвольные даты;
- рекомендации Эла: остановить, снизить расход, улучшить карточку или масштабировать;
- поиск по nmID, артикулу продавца и кампании;
- фото, артикул продавца, nmID и остаток в товарной таблице;
- безопасный режим: управление ставками и бюджетами отключено.

## Установка

Распакуйте архив в корень проекта Елисей и выполните:

```bash
node apply-ads-patch.mjs
npm run build
```

Для backend задайте:

```env
WB_PROMOTION_TOKEN=токен_категории_Продвижение
```

После деплоя проверьте:

```text
/api/ads/health
```

Installer создаёт резервные копии изменяемых файлов с суффиксом `.ads-backup`.
