# ELISEI 5.3.11 — Global Period + El Context

Патч рассчитан на ветку `ELISEI_V5_3_9_WB_STOCK_REPORT_REPAIR` / 5.3.10.

Что добавлено:

- единый переключатель: День / Неделя / Месяц / Период;
- произвольные даты «с — по»;
- сравнение с предыдущим аналогичным диапазоном;
- сохранение выбора в localStorage при переходах между разделами;
- автоматическая передача периода во все API-запросы;
- автоматическая передача периода и сравнения в контекст Эла;
- backend middleware `req.period`;
- фильтрация датированных массивов и SQL helper для KPI/агрегатов.

## Применение

1. Распакуйте этот архив рядом с проектом Елисей.
2. Запустите из корня проекта:

```bash
node apply-period-patch.mjs
```

Скрипт найдёт `src/pages/DashboardPage.jsx` или актуальный `App.jsx`, создаст резервную копию и подключит панель.

После применения:

```bash
npm run build
```

Для backend перезапустите сервис Render. В агрегирующих endpoint используйте `req.period` и helper `sqlPeriod`, как показано в `docs/PERIOD_CONTRACT.md`.
