# ELISEI 5.3.14 — исправление фильтра периода

Этот патч ставится **поверх 5.3.13**.

Он исправляет ситуацию, когда даты менялись на экране, но KPI и таблицы оставались прежними.

## Установка

Распакуйте архив в корень проекта и выполните:

```bash
node apply-period-runtime-fix.mjs
npm run build
```

Затем загрузите изменения и выполните Deploy latest commit на frontend и backend Render.

После выбора дня, недели, месяца или произвольного диапазона страница обновится один раз и все API-запросы уйдут с выбранными датами.
