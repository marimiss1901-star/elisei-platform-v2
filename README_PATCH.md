# ELISEI 5.3.15 — видимая панель периода

Ставится поверх 5.3.14.

Исправляет ситуацию, когда фильтр дат был подключён технически, но не отображался в интерфейсе.

После установки панель **«Период аналитики»** видна сверху основного контента на всех страницах:

- День
- Неделя
- Месяц
- Период
- Сравнить
- стрелки предыдущего/следующего периода

## Установка

Распаковать в корень проекта и выполнить:

```bash
node apply-period-visible-fix.mjs
npm run build
```

Затем выполнить Deploy latest commit для frontend.
