# ELISEI 5.3.17 — компактный рабочий фильтр периода

Патч заменяет длинную панель 5.3.16 на компактный фильтр в правой части верхней зоны приложения.

## Что изменено

- одна компактная кнопка с выбранным периодом;
- стрелки перехода к предыдущему/следующему периоду;
- быстрые варианты: сегодня, вчера, 7/30 дней, текущая/прошлая неделя, текущий/прошлый месяц;
- произвольный диапазон дат;
- сравнение с предыдущим аналогичным периодом;
- на странице «Остатки» — выбор «Остатки на дату»;
- фильтр скрывается на страницах «Товары», «Подключения» и «Импорт данных»;
- даты передаются в `fetch` и `XMLHttpRequest` до загрузки данных;
- подписи вроде «Выручка · 30 дней» обновляются под выбранный диапазон;
- старая панель и старые подключения периода удаляются из `index.html`.

## Установка

Распаковать файлы в корень репозитория Елисея. В Build Command frontend временно использовать:

```bash
npm install && node apply-period-smart-toolbar.mjs && npm run build
```

После успешного deploy команду можно оставить: установщик идемпотентный и не создаёт дубли.

## Проверка

В консоли браузера должна появиться строка:

```text
[ELISEI] Smart period toolbar 5.3.17 loaded
```

При изменении периода страница один раз обновится, чтобы все разделы повторно запросили данные с новыми датами.
