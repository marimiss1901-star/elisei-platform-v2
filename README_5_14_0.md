# ELISEI 5.14.0 — Business First Bootstrap

## Зачем
Новый магазин не должен ждать полной исторической синхронизации, чтобы увидеть полезную картину бизнеса.

## Новый порядок первичного подключения WB
Первый приоритет — две готовые управленческие витрины:

1. **Вчера** — завершённый календарный день.
2. **Последние 7 завершённых дней** — семь полных дней, заканчивающихся вчера.

Сегодняшний незавершённый день не входит в первую недельную витрину и не искажает сравнение.

## Что входит в первый поток
При наличии соответствующих категорий API-токена сначала загружаются:

- товары;
- заказы;
- продажи и возвраты;
- **финансы WB**;
- реклама;
- эквайринг;
- платное хранение;
- платная приёмка;
- затем текущие остатки FBS/FBO.

Финансы являются частью обязательной первой бизнес-картины, а не поздним обогащением.

## Что происходит потом
Пока первый бизнес-поток не готов, глубокая история и второстепенные потоки получают низкий bootstrap-приоритет. После готовности ядра ELISEI автоматически:

- освобождает остальные потоки;
- ставит в фон углубление истории;
- расширяет заказы, продажи, рекламу, финансы и эквайринг до 30 завершённых дней;
- не удаляет уже сохранённую картину «вчера / 7 дней».

Если WB сам не позволяет закрыть первый поток из-за временной ошибки, после 45 минут срабатывает защитный release: интерфейс продолжает работать с честным статусом частичных данных, а не зависает навсегда.

## Изоляция
Business First Bootstrap применяется только к совершенно новому подключению WB. Уже работающие кабинеты продолжают использовать обычный Smart WB Scheduler без изменения порядка текущих задач.
