# ELISEI 5.4.7A — Sync Watchdog Hotfix

Исправляет зависший статус «Загрузка» после перезапуска или падения backend Render.

## Что изменено

- этап `running`, который не обновлялся более 3 минут, автоматически переводится в `queued`;
- watchdog запускается при старте backend, каждые 30 секунд, при открытии страницы синхронизации и перед ручным запуском;
- зависший этап больше не блокирует FBS, финансы, хранение, приёмку и эквайринг;
- предыдущие данные не удаляются;
- новый запрос продолжает выполняться через существующую последовательную очередь.

## Установка

Загрузить папку `backend` в корень репозитория с заменой файла.

Render backend:
- Root Directory: `backend`
- Build Command: `npm install`
- Start Command: `npm start`

Затем `Manual Deploy → Clear build cache & deploy`.

Опциональная переменная:

`WB_STALE_RUNNING_MINUTES=3`

По умолчанию уже используется 3 минуты. Допустимый диапазон: 2–30 минут.
