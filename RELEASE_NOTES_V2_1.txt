ELISEI v2.1 WB Integration Foundation

- Добавлен отдельный Node.js backend.
- Реальная проверка токена через официальные WB API endpoints.
- Токен не сохраняется во frontend и не возвращается браузеру.
- Реальная синхронизация каталога, заказов, продаж и остатков.
- Dashboard получает выручку, число заказов, продаж и общий остаток.
- Раздел «Товары» показывает загруженный каталог Wildberries.
- Добавлены status/sync/disconnect API endpoints.
- Добавлена настройка VITE_API_BASE_URL.
- Добавлена инструкция развертывания двух сервисов на Render.

Прибыль и маржинальность намеренно не рассчитываются без себестоимости,
комиссий, логистики, рекламы и прочих расходов.
