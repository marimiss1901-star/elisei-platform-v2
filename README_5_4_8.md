# ELISEI 5.4.8 — полный реестр движений денег WB

Прямой патч без установщиков. Загружайте содержимое архива в корень репозитория с заменой файлов.

## Что добавлено

- Единый PostgreSQL-реестр `wb_finance_ledger` для всех денежных движений.
- Каждая операция хранит дату, сумму со знаком, FBS/FBO, nmID, артикул продавца, barcode, srid, заказ, склад, тип документа, название операции, исходное поле и источник API.
- Отдельно показываются:
  - продажа и розничная сумма;
  - сумма к перечислению продавцу;
  - комиссия WB;
  - прямая и обратная логистика;
  - отправка и доставка FBS;
  - хранение FBO;
  - платная приёмка;
  - эквайринг;
  - штрафы;
  - удержания;
  - корректировки;
  - компенсации и доплаты;
  - кешбэк и рассрочка, если присутствуют в отчёте WB;
  - детализация отдельных отчётов хранения, приёмки и эквайринга.
- Вкладки финансов: Обзор, Все операции, По товарам, FBS, FBO, Удержания и штрафы, Компенсации, Сверка с WB.
- Поиск по операции, артикулу, nmID, srid и заказу.
- Сверка компонентного расчёта с полем «к перечислению продавцу».
- Отдельные отчёты хранения, приёмки и эквайринга не суммируются повторно в P&L.
- До завершения финансового отчёта показывается статус ожидания, а не ложный ноль.

## Render backend

- Root Directory: `backend`
- Build Command: `npm install`
- Start Command: `npm start`

## Render frontend

- Root Directory: пусто
- Build Command: `npm install && npm run build`
- Publish Directory: `dist`

После загрузки выполните Clear build cache & deploy сначала backend, затем frontend.
