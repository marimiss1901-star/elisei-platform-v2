# ELISEI 5.10.4 — корректные лимиты финансов WB

Этот релиз исправляет ошибочную трактовку лимитов финансового API в 5.10.2–5.10.3.

### Что увидит текущий кабинет
Если WB уже вернул `429` и `nextAllowedAt` примерно через 12 часов, этот таймер **не исчезнет после деплоя** — это реальный лимит Base token без service secret. Прогресс и `rrdId` сохраняются, и worker продолжит загрузку после разрешённого времени.

### Что улучшится
Новые финансовые запросы используют `limit=100000`, поэтому вместо 10 000 строк ELISEI просит максимум до 100 000 строк за один вызов. Для небольших и средних кабинетов этого часто достаточно, чтобы получить практически весь выбранный период уже первым разрешённым запросом; окончательное подтверждение покрытия всё равно следует официальной пагинации до HTTP 204.

### Быстрый SaaS-режим
Пользователь по-прежнему подключает один ключ WB. После регистрации ELISEI как сервиса и настройки `WB_CLIENT_SECRET` на backend Base + secret / Service получают расширенные лимиты. Секрет не вводится продавцом и не показывается в UI.

Версии:
- Frontend 5.10.4
- Backend 2.22.4
- El Core 5.10.4
