# ELISEI 5.4.9 — расширенное покрытие WB API

Это прямой патч поверх установленной версии 5.4.8A. Он добавляет следующий критический слой read-only синхронизации и не изменяет MAXADORRE.

## Новые потоки

1. Архивные сборочные задания FBS — `/api/marketplace/v3/fbs/orders/archive`.
   - обязательные `year` и `month`;
   - постраничный `next`;
   - по умолчанию проверяются 24 архивных месяца;
   - настройка `WB_FBS_ARCHIVE_MONTHS` допускает 1–60 месяцев.
2. Удержания за занижение габаритов упаковки.
3. Подмены и неверные вложения.
4. Возвраты и перемещения товаров.
5. Комиссии и тарифы: категории, короба, паллеты, возврат продавцу.
6. Воронка карточек: открытия, корзины, заказы, выкупы, отмены и конверсии.
7. Список документов WB.

## Финансовая прозрачность

- штрафы за габариты и удержания попадают в единый финансовый реестр;
- возврат удержания `reversalAmount` сохраняется отдельной компенсацией;
- детализирующие отчёты помечены `detailOnly` и не прибавляются повторно к P&L;
- источник, исходная строка и поле суммы сохраняются для сверки.

## Память и продолжение

Архив FBS и постраничные отчёты записываются в PostgreSQL порциями. Курсоры `next`/`offset`, месяц архива и `syncId` сохраняются. После перезапуска Render задача продолжается с последней сохранённой позиции.

## Установка

Скопируйте содержимое папки патча в корень репозитория с заменой файлов.

Backend Render:

- Root Directory: `backend`
- Build Command: `npm install`
- Start Command: `npm start`

Frontend Render:

- Root Directory: пусто
- Build Command: `npm install && npm run build`
- Publish Directory: `dist`

Сначала выполните `Clear build cache & deploy` для backend, после успешного запуска — для frontend. Затем один раз запустите доступные этапы синхронизации.

## Важно

Версия 5.4.9 расширяет критическое покрытие, но не заявляет поддержку абсолютно всех методов WB API. Статистика всех рекламных кампаний, поисковые запросы, история остатков, отзывы, вопросы и чаты будут подключаться отдельными этапами, чтобы не смешивать большие изменения в одном релизе.
