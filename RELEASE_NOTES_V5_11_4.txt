ELISEI 5.11.4 — SKU 360 Data Isolation

Исправлена утечка поисковых фраз между товарами в SKU 360. В рентген SKU допускаются только строки rowType=query, доказуемо связанные с товаром по строгой identity-модели; обзорные/group строки исключены. Рекламные деньги в SKU 360 теперь принимаются только из campaign product rows с точным совпадением nmID; распределённый по кабинету рекламный расход из общего core больше не подменяет точный расход товара. Размер batch для WB /api/v2/search-report/product/search-texts ограничен 20 nmIds согласно актуальному контракту WB.
