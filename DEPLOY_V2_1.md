# Деплой ELISEI 5.4.0 на Render

## 1. Backend

1. Откройте Web Service backend.
2. `Manual Deploy` → `Clear build cache & deploy`.
3. После запуска откройте `/health`.
4. Проверьте:

```json
{
  "ok": true,
  "service": "elisei-api",
  "version": "2.8.0",
  "database": "ok"
}
```

## 2. Frontend

1. Откройте Static Site frontend.
2. `Manual Deploy` → `Clear build cache & deploy`.
3. После завершения нажмите `Ctrl + F5`.

## 3. Первичная синхронизация после обновления

1. API-токен не удалять и не вводить повторно.
2. Открыть «Синхронизации».
3. Запустить «Товары».
4. После успешного каталога запустить «Остатки» один раз.
5. Дождаться фонового статуса `done`.
6. Проверить блок целостности:
   - карточки и ШК каталога;
   - сопоставленное количество остатков;
   - кампании со статистикой.

Старые снимки остатков ниже схемы 5 не публикуются. Новый отчёт создаётся с разбивкой по артикулу продавца, nmID, баркоду и размеру.
