# ELISEI 5.6.2 — единый период и фильтры кабинета

Прямое обновление поверх **ELISEI 5.6.1**. MAXADORRE и его данные не затрагиваются.

## Главное

Выбранный период больше не относится только к странице «Аналитика». Он применяется к рабочим разделам:

- остатки и скорость продаж;
- финансовый реестр, P&L, отчёты и динамика;
- реклама, кампании, товары и дневные показатели;
- поисковые запросы;
- история остатков;
- отзывы, вопросы и события чатов.

Период сохраняется при переходе между страницами и не сбрасывает выбранный раздел.

## Единый поиск и фильтры

- общий поиск по товару, артикулу продавца, nmID, бренду, штрихкоду и тексту операции;
- фильтр состояния остатков;
- фильтры рекламных кампаний по статусу;
- поисковые строки по типу отчёта;
- история остатков по наличию и складу;
- отзывы и вопросы по статусу ответа;
- отзывы по оценке;
- чаты по типу строки: диалог или событие;
- серверная фильтрация и постраничная выдача больших потоков.

## Точность данных

- финансовые строки и суммы ограничиваются выбранными датами на backend;
- рекламная статистика пересчитывается по дневным данным выбранного периода;
- при неполном покрытии ELISEI показывает фактический диапазон, а не нули;
- поисковый отчёт не разрезается приблизительно: для другого периода создаётся новый отчёт WB;
- история остатков ограничивается официальным окном до 90 дней;
- рекламный запрос ограничивается окном до 31 дня;
- числовые Unix-даты событий чатов корректно преобразуются перед фильтрацией;
- текущий остаток остаётся текущим снимком, а продажи и дни покрытия пересчитываются за выбранный период.

## Исправление финансового интерфейса

Во frontend API-клиент добавлен отсутствовавший метод `financeLedger`. Финансовый экран теперь обращается к реальному backend-маршруту и использует единый период и общий поиск.

## Версии

- Frontend: `5.6.2`
- Backend: `2.14.0`
- Потоков WB: `27`

## Установка

Архив является патчем поверх версии 5.6.1. Скопируйте его содержимое в корень репозитория с заменой файлов.

Backend Render:

- Root Directory: `backend`
- Build Command: `npm install`
- Start Command: `npm start`

Frontend Render:

- Root Directory: пусто
- Build Command: `npm install && npm run build`
- Publish Directory: `dist`

Сначала выполните **Clear build cache & deploy** для backend, затем для frontend. После запуска обновите кабинет через `Ctrl + F5`.
